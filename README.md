# AW139 Fuel Cal

เครื่องคำนวณปริมาณเชื้อเพลิงสำหรับ AW139 (KG / LITER)

**ลิงก์:** https://sayumphu111-collab.github.io/A139-Fuel-Cal-KG-to-Liters-sw./

## ฟีเจอร์

| แท็บ | รายละเอียด |
|------|------------|
| ⛽ **เต็มถัง** | คำนวณปริมาณที่ต้องเติมให้เต็มถัง (เป้าหมาย 1,270 KG) |
| ◎ **ตามเป้า** | กำหนดปริมาณเป้าหมายเอง แล้วคำนวณส่วนต่าง |
| ⇄ **แปลงหน่วย** | แปลง KG ↔ Liter (1 KG = 1.25 L) |
| 📋 **ประวัติ** | บันทึกและดูประวัติการเติม (สูงสุด 20 รายการ) |
| ⓘ **วิธีใช้** | คำอธิบายการใช้งาน |

## วิธีติดตั้งบนมือถือ

### Android (Chrome)
1. เปิดลิงก์ด้วย Chrome
2. กดปุ่ม **⬇ ติดตั้งแอป** หรือเมนู ⋮ → ติดตั้งแอป

### iPhone (Safari)
1. เปิดลิงก์ด้วย Safari
2. กดปุ่ม Share → **Add to Home Screen**

## การใช้งานสั้น ๆ
- ช่องสีเหลือง = กรอกข้อมูล
- ช่องสีฟ้า = ผลคำนวณ
- กดปุ่ม **บันทึกประวัติ** ในแท็บเต็มถัง / ตามเป้า เพื่อเก็บข้อมูล
