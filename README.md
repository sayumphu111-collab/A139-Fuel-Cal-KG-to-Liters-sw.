# Fuel Calculator App

เครื่องคำนวณปริมาณเชื้อเพลิง (KG / LITER) แบบแอป

## ติดตั้งบนมือถือ (แนะนำ)

### Android
1. เปิดด้วย **Chrome**
2. กดปุ่ม **⬇ ติดตั้งแอป** ที่ด้านล่าง  
   หรือกดเมนู ⋮ → **ติดตั้งแอป** / **เพิ่มไปยังหน้าจอหลัก**

### iPhone
1. เปิดด้วย **Safari**
2. กดปุ่ม **Share** → **Add to Home Screen**

หลังติดตั้งจะเปิดแบบแอปเต็มจอ ไม่มีแถบเบราว์เซอร์

## ฟีเจอร์
- คำนวณเติมเต็มถัง
- คำนวณตามเป้าหมาย
- แปลงหน่วย KG ↔ Liter
- บันทึกค่าล่าสุดอัตโนมัติ
- ใช้งานออฟไลน์ได้
